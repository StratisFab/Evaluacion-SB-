# Playwright Java Gradle Example

Este es un proyecto base listo para usar con Playwright, Java y Gradle.

## Requisitos
- Java 11 o superior instalado.

## Cómo ejecutarlo
1. Descomprime este archivo e ingresa a la carpeta desde tu terminal.
2. Ejecuta el comando de Gradle correspondiente a tu sistema operativo:

   **En Linux/macOS:**
   ```bash
   ./gradlew test
   ```

   **En Windows:**
   ```cmd
   gradlew.bat test
   ```

Nota: La primera vez que corra, Playwright descargará automáticamente los navegadores necesarios (Chromium, Firefox, WebKit).
